# 初回訪問時の操作ガイド（オンボーディング）実装計画

「🎧 ここから再生」のふきだしが好評だったので、**同じ見た目のふきだしを、操作の順番どおりに**
出して初めての人を案内する。この文書は実装前の合意用で、コードはまだ入れていない。

## 1. 方針

- 既存の `hasPlayedOnce` のふきだしと**同じ意匠**（teal のピル、`animate-bounce`、`pointer-events-none`）を使う。
  新しいUI言語を持ち込まない。
- **モーダルで画面を覆わない**。暗幕（オーバーレイ）で操作を止める方式は、審査員のデモ中に事故になるので採らない。
  ふきだしは常に `pointer-events-none` で、本人の操作を一切邪魔しない。
- **手順は「次へ」で送らない**。案内された操作を**実際にやったら次に進む**（＝操作が進行のトリガー）。
  読まずに閉じる人も自然に前に進む。
- 状態の保存先は **`localStorage`**（Cookie ではない）。サーバー側で読む必要がなく、
  Workers のキャッシュにも影響しないため。キーは `afg.tour.v1`。
- 初回かどうかの判定はマウント後に行う（SSR とハイドレーションのずれを避けるため、
  最初のレンダリングでは必ず非表示）。

## 2. 案内する手順（この順番）

| # | 案内するUI | ふきだし文言（ja） | 次に進む条件 |
|---|---|---|---|
| 1 | 作品名の入力欄（`#artwork`） | 作品名を入れてみてください | 解説の生成が始まった |
| 2 | 中央の再生ボタン | 🎧 ここから再生 | 一度再生した（＝現在の `hasPlayedOnce`） |
| 3 | 見どころ（画像上のホットスポット） | 絵の上の光る点が「見どころ」です | ホットスポットを開いた |
| 4 | 裏話・エピソードのボタン | もっと知りたければ、裏話もあります | 裏話を取得した |
| 5 | 質問の入力欄 | 疑問はその場で訊けます。答えは解説に残ります | 質問を送った |
| 6 | 言語切替（ヘッダー） | 5言語で聴けます | 言語を変えた／または手順5から一定時間後に自動終了 |

- 手順1は、URL 直リンク（`/water-lilies` など）で来た人には**飛ばす**（すでに作品が決まっているため）。
- 手順3は、その作品に見どころが無い場合は飛ばす。
- 各ふきだしは**その手順の対象が画面に見えているときだけ**表示する。

## 3. 途中でやめられるようにする

- ふきだしの右端に小さな `×`。押すと以降の全手順を出さず、`localStorage` に完了として記録する。
- 手順が進まないまま **60秒** 経ったら、その手順のふきだしは自然に消える（しつこくしない）。
- ヘッダーのメニューに「操作ガイドをもう一度」を置き、`localStorage` を消して手順1から出し直せるようにする
  （デモの再演で必要になる）。

## 4. 文言は5言語ぶん用意する

`src/lib/i18n.ts` の `UIStrings` に `tour` セクションを追加する（ja/en/fr/zh/es）。
既存の `playHere` は手順2の文言としてそのまま再利用し、重複した文言を作らない。

```ts
tour: {
  enterTitle: '作品名を入れてみてください',
  hotspot: '絵の上の光る点が「見どころ」です',
  deepDive: 'もっと知りたければ、裏話もあります',
  ask: '疑問はその場で訊けます。答えは解説に残ります',
  language: '5言語で聴けます',
  dismiss: '閉じる',
  restart: '操作ガイドをもう一度',
}
```

## 5. 実装の形

`HomeClient.tsx` は既に大きいので、案内の状態管理は**外に出す**。

- `src/hooks/useOnboardingTour.ts` — 現在の手順を返すフックひとつ。
  `localStorage` の読み書き、手順の前後関係、60秒での消滅、`×` での終了をここに閉じ込める。
- `src/components/TourHint.tsx` — ふきだしの見た目だけを持つ小さな部品。
  既存の再生ボタンのふきだしもこれに置き換えて、意匠を一箇所にする。
- `HomeClient.tsx` 側の変更は、対象のUIの隣に `<TourHint step="…" />` を置き、
  既存のハンドラから `tour.complete('…')` を呼ぶだけに留める（状態機械には手を入れない）。

これで差分は「新規2ファイル＋i18nの追記＋HomeClient に数行」に収まる。

## 6. 確認すること

- `npx tsc --noEmit` と `npm run build`
- 初回訪問で手順1から出る／リロードしても続きから出る／完了後は二度と出ない
- 5言語すべてでふきだしがはみ出さない（中国語は短く、フランス語は長い）
- モバイル幅（375px）で横スクロールが出ない
- ふきだしが下のボタンのタップを妨げない（`pointer-events-none` の確認）

## 7. 判断が必要な点

- **手順の数**: 上の6手順は「全部入り」。デモで長いと感じるなら 1・2・3 の3手順に絞る案もある。
- **初回の定義**: `localStorage` は端末＋ブラウザ単位。ログイン済みユーザーの端末をまたいだ引き継ぎは
  今回はやらない（Supabase に持たせる話になり、当日の変更としては重い）。
