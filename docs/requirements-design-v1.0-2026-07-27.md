**ドキュメント名:** ArtFreeGuide 要件定義書 v1.0
**作成日:** 2026-07-27
**状态:**  draft（Antigravityの現行作業を完成后に再開）
**対象プロジェクト:** ArtFreeGuide

---

## 1. 概要と背景

### 1.1 目的

ArtFreeGuideのUI/UXを刷新し、利用者との対話型协創を通じて美術作品のナレッジベースを継続的に성장させる自律型エージェントを目指す。

### 1.2 現状の課題

| 課題 | 詳細 |
|------|------|
| 按钮过多 | フィードバック・評価・送信・再生など複数の按钮が別れいている |
| 画面遷移が発生 | 作品詳細页への遷移があり、対話を中断させる |
| プレイリストが别画面 | 作品一覧から别画面に遷移する必要がある |
| 反馈の非効率 | フィードバックが活用されるかわからない |

### 1.3 新しい设计の原則

```
1. 单一画面 — 画面遷移を完全になくし、1つの画面で全操作を行う
2. 按钮共通化 — 再生ボタンと送信ボタンを1つの[▶]按钮に統一
3. 全情報が同一画面 — 解説、サジェスト、プレイリスト、入力框が同一画面に表示
4. AIとの対話による协創 — 利用者の入力をAIが自律処理し、知識基盤成长为
```

## 2. ユーザー体験設計（UX Vision）

### 2.1 ユーザーが体験すること

```
あなた：マグリットの『レディメイドの花束』について教えて
AI：    「1957年、大阪中之島美術館所蔵の作品で…」

あなた：（テキストを入力）「更多信息知りたい」
AI：    「この作品的、次は如何ですか？类似的作品がおすすめです」

あなた：（再生ボタン押す）
AI：    音声が再生される

あなた：（プレイリストの画像をタップ）
→ 別の作品に切り替え（画面遷移なし）
```

### 2.2 协創の実感

利用者は以下を提供するたびに、知識基盤が成長していることを確認できる：

| 利用者の行动 | AIの反応 | 成長内容 |
|-------------|---------|---------|
| 「信息来源错了」 | 「修正しました」 | DBの情報が修正される |
| 「この作品的信息谁知道？」 | 「探してみます」→見つけた情報 | DBに不足情報が補完される |
| 「新しい作品を見てたい」 | 推荐作品を表示 | プレイリストが活用される |

### 3.2 コンポーネント一覧

| # | コンポーネント名 | 役割 | 状態 |
|---|----------------|------|------|
| 1 | Header | グローバルナビゲーション | 常時表示 |
| 2 | ArtworkDisplay | 作品解説・会話履歴・AI応答を表示 | 常時表示 |
| 3 | SuggestBar | サジェスト按钮＋作品/プレイリスト画像を横一列に表示 | 常時表示 |
| 4 | InputArea | テキスト入力 + [▶]共通ボタン | 常時表示 |
| 5 | AudioPlayerBar | 音声再生コントロール | 常時表示 |

### 3.3 [▶ 再生/送信] 按钮の動作仕様

**状态判定逻辑：**

```
IF inputValue.trim() !== "" THEN
  // 送信モード
  - AIにテキストを送信
  - 解説エリアにAI応答を追加表示
  - 入力欄をクリア
ELSE
  // 再生モード
  - 現在の解説テキストを音声再生
  - 再生位置から續行（もしあれば）
END
```

### 3.4 サジェストボタン（固定5种）

| 按钮名 | タップ時の動作 |
|--------|--------------|
| `[次に読む]` | 関連・同类作品を推荐。解説エリアに推荐作品を表示 |
| `[もっと深く]` | 詳細ガイド（guide_deep）を解説エリアに表示 |
| `[他のマグリット]` | マグリットの他の作品を列表 |
| `[登録する]` | 新規作品を登録するフローを開始（解説エリア内で誘導） |
| `[別の画家]` | 他の画家を推荐 |

### 3.5 作品/プレイリスト画像の配置

**横スクーロох:**

```
[サジェスト5按钮]  │作品1│作品2│作品3│作品4│ ... │📋PL1│📋PL2│📋PL3│
                  ──── 作品画像 ────    ────── プレイリスト画像 ──────
```

- 左側：サジェスト按钮（固定、幅狭）
- 中央：作品のサムネイル画像（横스크ロール）
- 右側：プレイリスト画像（横スクール）
- タップした画像に応じて、解説エリアの内容が切换

## 4. 機能仕様

### 4.1 AI对话機能

**入力:** ユーザーが入力したテキスト
**出力:** AI応答（解説エリアに表示）
**処理内容:**

| ユーザーの入力例 | AIの自律対応 |
|----------------|------------|
| 「信息来源错了」 | DB検証→修正→「修正しました」と応答 |
| 「次見たい作品は？」 | 関連作品を推荐 |
| 「もっと深く教えて」 | guide_deepの詳細を生成 |
| 「新しい作品を登録したい」 | 登録フローへ誘導 |
| 「ありがとう」 | 「大切です次回もどうぞ」と応答 |
| （空欄で[▶]） | 音声再生を実行 |

### 4.2 非同期情報補完

**触发条件:** ガイド生成時に不足情報（gaps）が検出された場合
**动作:** バックグラウンドでWeb搜索→DB更新（利用者は待たない）
**结果:** 次回同じ作品がリクエストされた时可変数値が埋まっている

### 4.3 プレイリスト機能

**表示:** サジェストバーに横一列で画像预览を表示
**タップ時:** そのプレイリストの詳細に切り替え（解説エリアが更新される）
**画面遷移:** なし（单一画面内で完結）

### 4.4 音声再生機能

**対応范围:**
- 現在の解説テキスト全体の再生
- 一時停止/再開
- 速度変更（0.75x, 1.0x, 1.25x, 1.5x, 2.0x）
- 位置操作（前後スキップ）

## 6. 実装 Phase 分割

### Phase 1: 最小回路の検証
**目的:** 核心机制（テキスト入力→AI応答→表示）の動作確認

| 項目 | 内容 |
|------|------|
| 追加 | テキスト入力欄（textarea） |
| 追加 | [▶ 送信]ボタン（一時的に送信だけ） |
| 追加 | AI応答を解説エリアに表示する機構 |
| 维持 | 既存の全UI（変更なし） |
| 削除 | なし |

**受け入れ基準:**
- [ ] テキストを入力して送信を押すと、AI応答が解説エリアに表示される
- [ ] 既存の再生ボタン・フィードバックボタンが正常に動作する
- [ ] エラー発生時、既存の画面に恶影響がない

---

### Phase 2: ボタン共通化の検証
**目的:** [▶]ボタンで再生・送信の両方を行えることの動作確認

| 項目 | 内容 |
|------|------|
| 変更 | [▶ 送信]ボタンを[▶ 再生/送信]に改名 |
| 追加 | inputValueの状態監視ロジック |
| 変更 | 空欄時→音声再生、それ以外→テキスト送信 |

**受け入れ基準:**
- [ ] テキスト入力ありで[▶]→テキストが送信され、AI応答が表示される
- [ ] 空欄で[▶]→音声が再生される
- [ ] 既存の再生コントロールバーが正常に動作する

---

### Phase 3: 旧按钮の段階的撤去
**目的:** 不要になった按钮を安全なタイミングで撤去

| 段階 | 处置 | 受け入れ基準 |
|------|------|-------------|
| 3-1 | フィードバックボタンを非表示化 | [ ] ページに表示されていないことを確認 |
| 3-2 | 評価ボタンを非表示化 | [ ] ページに表示されていないことを確認 |
| 3-3 | 送信専用按钮を削除（ если Phase2完了） | [ ] [▶ 再生/送信]のみで送信・再生が動作する |

**受け入れ基準:**
- [ ] 各段階で該当する按钮が页面から消えている
- [ ] 用户的 操作에 影响がっていない

---

### Phase 4: 单一画面化の検証
**目的:** 画面遷移を减らし、同一画面での操作を可能にする

| 項目 | 内容 |
|------|------|
| 追加 | プレイリスト画像をサジェストバーに表示 |
| 追加 | 作品画像をタップ→解説エリアが切换（遷移なし） |
| 变更 | 作品詳細页面への拉手 기능을 单一画面내部的切换に置き換え |

**受け入れ基準:**
- [ ] プレイリスト画像がサジェストバーに表示される
- [ ] 作品画像をタップすると解説エリアが更新される（画面遷移なし）
- [ ] [←]ボタンで明细画面に戻る動作が不需要になる

---

### Phase 5: 最終UI调整
**目的:** すべての组件を統合·調整し、完全な单一画面を实现

| 項目 | 内容 |
|------|------|
| 变更 | すべての旧按钮を削除（Phase 3完了後） |
| 追加 | サジェスト按钮と作品/プレイリスト画像の横一列配置 |
| 調整 | 各コンポーネントの幅·配置の 최종调整 |
| 确认 | 全画面이单一画面内で動作すること |

**受け入れ基準:**
- [ ] 单一画面に全要素（解説エリア、サジェスト、入力框、操作バー）が表示される
- [ ] 画面遷移が完全に発生しない
- [ ] すべての按钮が期待通りに動作する

## 7. バックエンド API 仕様

### 7.1 `POST /api/chat`

**目的:** AI对话を処理

**リクエスト:**
```json
{
  "message": "string",       // ユーザーの入力テキスト
  "artworkId": 27,          // 現在の作品ID
  "artworkTitle": "...",    // 現在の作品名
  "artistName": "...",      // 現在の作者名
  "history": [              // 任意の会話履歴（省略可）
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ]
}
```

**レスポンス:**
```json
{
  "reply": "string",       // AIの応答テキスト（解説エリアに表示）
  "action": "string",       // 動作区分
  "metadata": {}            // 追加情報（オプション）
}
```

**action区分:**
- `CORRECTION_APPLIED` — 情報を修正、DBに保存された
- `RECOMMENDATION` — 作品を推荐した
- `GUIDE_EXPANSION` — 詳細ガイドを生成した
- `GREETING` — 単純な応答

### 7.2 `GET /api/artworks/recommend?artworkId=XX`

**目的:** 関連作品とプレイリスト画像を推荐

**レスポンス:**
```json
{
  "recommendations": [
    {"id": 123, "title": "...", "artist": "...", "imageUrl": "...", "type": "artwork"},
    {"id": 456, "title": "...", "imageUrl": "...", "type": "playlist"}
  ]
}
```

    ▼

                                                ▼

                                        ・DB更新
                                        ・推荐生成
                                        ・情報補完

## 9. 状態管理

**React State（ArtFreeGuideClient.tsx）:**

```typescript
// 入力管理
const [inputValue, setInputValue] = useState('');

// 解説エリア表示用
const [displayText, setDisplayText] = useState('');  // 現在のガイドテキスト
const [conversationLog, setConversationLog] = useState<string[]>([]);  // AI応答の履歴

// 作品情報
const [currentArtwork, setCurrentArtwork] = useState<Artwork | null>(null);

// 音声状態
const [isPlaying, setIsPlaying] = useState(false);
const [playbackPosition, setPlaybackPosition] = useState(0);

// [▶]ボタン逻辑
const handleMainAction = () => {
  if (inputValue.trim()) {
    // 送信モード
    submitToChat(inputValue);
    setInputValue('');
  } else {
    // 再生モード
    playNarration(displayText, playbackPosition);
  }
};
```

## 10. 非機能要件

| 要件 | 基準 |
|------|------|
| 応答速度 | AI返答が5秒以内に表示されること |
| 兼容性 | iPhone SE（375px）から-desktopまで対応 |
| アクセシビリティ | 音声読み上げ対応、ボタンの достаточные 크기 |
| キャッシュ | artworkデータの客户端キャッシュで的高速表示 |

## 11. リスクと对策

| リスク | 対策 |
|--------|------|
| 全部署を一括で行うと问题の特定が困難 | Phase分割して各Phaseごとに検証 |
| AI返答が長時間かかる | 非同期処理、加载中のインジケーター表示 |
| 单一画面だと情報が多い | スクロール·折叠で視認性を维持 |
| 既存のreticleユーザーが困る | Phase 1では既存UIを維持し、慣らし期間を設ける |

---

## 12. 用語定義

| 用語 | 定義 |
|------|------|
| 单一画面 | ページ遷移が発生しない、1つの视图上で全操作を行うUI形态 |
| [▶ 再生/送信] | 再生と送信の2つの 기능을兼务する单一的ボタン |
| サジェスト | 利用者の次の行動を诱导する固定的ボタン郡 |
| 协創 | 利用者の入力とAIの处理が組み合わさり、知識基盤が成长すること |
| gaps | 作品情報の不足分（画像URL、年份、所蔵美術館など） |
| 非同期補完 | 利用者を待たせず、背後でAIが情報を补完すること |
