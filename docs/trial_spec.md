# ArtFreeGuide trialブランチ 機能拡張仕様書 (暫定)

## 1. 概要
`trial` ブランチでは、単発の作品解説ツールから、「個人の鑑賞履歴を管理し、詳細な解説モードを使い分けるパーソナライズされたガイド」への進化を目指していた。

## 2. 追加・変更機能詳細

### 2.1 履歴管理システム (Session Persistence)
- **目的**: 過去に検索した作品を保存し、簡単に再訪できるようにする。
- **実装内容**:
    - `localStorage` (`art_free_guide_history`) への保存と復元。
    - 履歴インデックス (`historyIndex`) による前後移動。
    - 履歴サイドバー (`showHistorySidebar`) による視覚的な履歴管理。
    - 保存項目: 作品名、アーティスト名、各モードの解説文、画像URL、推奨作品など。

### 2.2 解説モードの多層化 (Multi-layered Explanation)
- **目的**: ユーザーの興味レベルに合わせて、情報の密度を切り替えられるようにする。
- **モード定義**:
    - `short`: 要点のみの簡潔な解説。
    - `standard`: 標準的な解説。
    - `deep`: 深掘りした詳細な解説。
- **挙動**: モード切り替えにより、表示されるテキスト量と音声再生範囲が動的に変化する。

### 2.3 UI/UX のモダン化 (Modern Interface)
- **入力インターフェース**: 
    - 常時表示ではなく、スライドアップ式の「入力ドロワー」 (`showInputDrawer`) を採用し、コンテンツ表示領域を最大化。
- **レイアウト**:
    - 固定ヘッダーと、スクロール可能なコンテンツエリアの分離。
    - ボトムに固定された再生コントロールパネル。
- **フィードバック**: 
    - ユーザー操作に対する「トースト通知」 (`showToast`) の実装。
- **メニュー**: 
    - 再生速度を直感的に変更できる速度選択メニュー (`showSpeedMenu`)。

### 2.4 URL同期とディープリンク (Deep State Sync)
- **目的**: 特定の作品・モード・速度の状態をURLで共有可能にし、リロード後も状態を維持する。
- **実装内容**:
    - `window.history.replaceState` を使用し、URLパラメータ (`artwork`, `artist`, `speed`, `mode`) をリアルタイムに同期。
    - ページロード時にURLパラメータを解析し、自動的にガイドを生成する。

### 2.5 音声再生エンジンの高度化 (Audio Engineering)
- **目的**: 音声の途切れ、重複、停止時のハングを排除し、シームレスな体験を作る。
- **試行したアプローチ**:
    - `AudioController` 的な単一責任クラスへの再構成（コードベースでは `AudioController` 的なロジックを統合しようとしていた）。
    - `cancelSpeechQueue` による徹底したキュー管理。
    - 2.5秒のタイムアウトフォールバックの実装。
    - `speechSynthesis` の `resume` 処理によるブラウザ制限の回避。

## 3. 発生した課題 (Technical Debt)
- **状態更新の連鎖**: 履歴の切り替え $	o$ 各種 State 更新 $	o$ 再レンダリング $	o$ 音声再生トリガー という連鎖が発生し、音声エンジンが不安定化した。
- **副作用の競合**: `localStorage` への書き込みと音声再生の非同期処理が干渉し、音声が再生されない、あるいは途中で止まるバグが発生。

## 4. 回復への指針 (Recovery Path)
- **ロジックの分離**: UI状態 (ドロワーの開閉など) と、ドメインロジック (音声再生、API取得) を明確に分離する。
- **単方向データフローの徹底**: 履歴の変更が音声再生に影響を与えるパスを整理し、明示的な「再生開始」イベントのみが音声を制御するようにする。
- **本番ベースのUI移植**: 安定している音声ロジックをコアに据え、UIコンポーネントのみを `trial` の設計に従って再実装する。
