## 画面デザイン（確定）

```
┌─ mode toggle: 概要 / 標準 / 詳細 ──────────────────┐

┌─ チャット入力エリア ───────────────────────────────┐
│  textarea: 質問する or 改善点を伝える...            │
│                                                     │

│                                                     │

┌─ Highlights Segment Box ───────────────────────────┐

│                                                     │

│                                                     │
│  【修正済み解説テキスト】                           │ ← 改善後の解説
└─────────────────────────────────────────────────────┘

┌─ 最下部バー: ⏮ ▶ ⏭ 🔊 ─────────────────────────┐
```

## 実装タスク

### Task 1: API - /api/suggest 拡張（mode=improve）
- **ファイル:** `src/app/api/suggest/route.ts`
- **追加:** `mode=improve` パラメータ対応
- **AI処理:**
  1. segmentsテキストを受け取る
  2. 問題検出: `\n`文字、マークダウン崩れ、コンテンツ不足
  3. 最大3つのサジェストを返す

### Task 2: UI - サジェストUI追加
- **ファイル:** `src/app/ArtFreeGuideClient.tsx`
- **追加:**
  - `suggestions` state（AI生成サジェスト保持）
  - サジェスト表示エリア（textareaの下）
  - サジェストタップ時の処理

### Task 3: API - /api/chat 拡張（改善アクション対応）
- **ファイル:** `src/app/api/chat/route.ts`
- **追加アクション対応:**
  - `fix_format`: `\n` → 改行に変換、マークダウン修復
  - `expand_era`: 時代背景の詳細解説追加
  - `add_examples`: 具体例追加
  - `rephrase`: 自然语言に修正

### Task 4: 改善結果の表示
- **ファイル:** `src/app/ArtFreeGuideClient.tsx`
- **動作:** 改善実行後、修正済み解説をHighlights Segment Boxの先頭に追加表示
