# スライド画像／デモ動画 生成プロンプト集

画像生成は Midjourney / DALL·E / Imagen / Nano Banana 系、動画生成は Sora / Veo / Runway / Kling 系を想定。
日本語プロンプトが通らないツール向けに英語版も併記する。

実際に発表で使うスライド画像は、生成AIではなく `docs/slides/*.html` を Chrome ヘッドレスで撮影して
`docs/images/slides/*.png` に出力している（作り方は `docs/brand/README.md`）。このプロンプト集は、
差し替え用の背景素材や、生成動画の「引き」「締め」カットを作るときに使う。

---

## 0. 世界観（全カット共通・毎回貼る）

ブランドの核は **「暗い展示室に、床から立ち上がる金色のスポットライト」**。
README・OGP・サイトのバナーがすべてこの世界観で統一されているので、スライドと動画も同じにする。

```
共通スタイル指定（各プロンプトの末尾に必ず付ける）:
深い紺色から黒へのグラデーション背景（#020617〜#0f172a）、
アクセントは金色・琥珀色（#fde68a）のみ。
光は必ず下から上へ立ち上がるスポットライト（美術館の床置き照明）。
文字は明朝／セリフ体、余白は広く、要素は少なく、静か。
彩度は低く、金色だけが光る。ネオン・虹色・グラデ多用・3Dぬめり質感は禁止。
16:9、余白多め、上下に文字を載せられる空きを残す。
```

```
Common style suffix (English):
deep navy-to-black gradient background (#020617 to #0f172a),
single accent colour: warm gold / amber (#fde68a),
light always rising from the floor upward like museum uplighting,
elegant serif typography, generous negative space, minimal, quiet, cinematic,
low saturation except the gold, no neon, no rainbow gradients, no glossy 3D render,
16:9, room left at top and bottom for captions
```

**著作権の注意（重要）**: 睡蓮・星月夜などの実作品を「そのまま再現」させない。
`抽象化した睡蓮のモチーフ`（水面と葉の形だけ）、`渦を巻く夜空の抽象`のように **モチーフの抽象化** として指示する。
実際の作品画像が必要な場面は、アプリが使っている Wikimedia Commons のパブリックドメイン画像を使うのが安全かつ正確。

## 1. スライド用 画像生成プロンプト

### 1-1. 表紙 / タイトル

```
美術館の暗い展示室。中央に一枚の額縁だけがあり、床に置かれた照明が下から
金色の光をまっすぐ立ち上げて額縁を照らしている。額の中は具象画ではなく、
睡蓮の水面を極端に抽象化した青と金の色面。人物は写さない。
床には光の帯が薄く反射している。画面上部三分の一は暗く空けておく（タイトルを載せるため）。
＋共通スタイル指定
```

```
English:
a dark museum gallery, one single ornate frame at the centre, a floor-standing
light throwing a shaft of gold upward across it, inside the frame an extreme
abstraction of a water-lily pond in blue and gold colour fields, no people,
faint reflection of the light on the polished floor, top third of the image
left dark and empty for a title
+ common style suffix
```

載せる文字（画像に焼き込まず、スライド側でテキストとして重ねるのが綺麗）:

- 大見出し: **ArtFreeGuide**
- 副題: **聴くほど賢くなる、美術館のAI音声ガイド**

### 1-2. 課題（なぜ作ったか）

```
美術館の壁に掛かった一枚の絵の前で、来館者が「音声ガイド 貸出 有料」の
小さな札の前で立ち止まっているシルエット。人物は影のみ、顔は描かない。
札と絵は金色の下からの光でわずかに照らされ、周囲は暗い。
静かで、少し寂しい空気。
＋共通スタイル指定
```

載せる文字: **解説は、借りないと聴けない。借りても、その解説は一生変わらない。**

### 1-3. 解決（プロダクト紹介・スマホ実機）

生成画像より **実機スクリーンショット** のほうが強い。

```
docs/images/hero.png と docs/images/01-guide.png をスライドに貼り、
背景に 1-1 の生成画像を敷いて、スマホ枠に金色の細いふちと下からの光を重ねる。
```

生成で背景だけ作る場合:

```
何も置かれていない暗い美術館の床と壁だけの空間。床の一点から金色の光が
上へ扇状に広がっている。中央は完全に空白（あとからスマホのスクリーンショットを
合成するため）。
＋共通スタイル指定
```

### 1-4. 「聴くほど賢くなる」学習ループの図（発表の主役）

図はAI生成よりも作図が正確。

```
生成用:
暗い背景に、金色の細い線で描かれた円環のダイアグラム。円環上に4つの小さな
節点があり、それぞれに小さなアイコン（吹き出し・虫眼鏡・チェックマーク・波形）。
円環の中心に一枚の額縁のシルエット。線は細く上品で、光は下から。
文字は入れない（あとで日本語を載せる）。
＋共通スタイル指定
```

円環に載せる文字（時計回り）:

1. **聴く** — AIキュレーターが解説を読み上げる
2. **訊く／深掘る** — 質問と裏話がその場で生成される
3. **残る** — 回答と裏話が解説アーカイブ（D1）に追記される
4. **育つ** — 指摘は承認キューへ、履歴は好みベクトルへ。次の来訪者にはより賢いガイドが届く

### 1-5. 多言語

```
暗い展示室に、金色の光の中に浮かぶ5つの細い縦のプレート。
それぞれに JA EN FR ZH ES の2文字だけがセリフ体で刻まれている。
プレートは金の縁取り、背景は暗い。装飾は最小限。
＋共通スタイル指定
```

載せる文字: **日・英・仏・中・西 — 画面も解説も読み上げも、5言語。**

### 1-6. アーキテクチャ

生成画像ではなく構成図として作る（審査員は正確さを見る）。要素は `docs/slides/06-architecture.html` を参照。

背景だけ生成する場合:

```
暗い紺色の面に、金色の細い線でできた幾何学的なグリッド。左下から右上へ
淡い光が抜けている。中央は情報を載せられるよう暗く平坦。図形や文字は入れない。
＋共通スタイル指定
```

### 1-7. クロージング

```
暗い展示室の出口。開いた扉の向こうから金色の光が床に長く伸びている。
人物は写さない。静かで余韻のある画。中央下部は暗く空けておく（URLを載せる）。
＋共通スタイル指定
```

載せる文字:

- **聴くほど賢くなる、美術館のAI音声ガイド**
- `art-free-guide.taira-sakakibara.workers.dev`

## 2. README / OGP 画像を作り直す場合

`docs/images/ogp.png` と `hero.png` は HTML+CSS から生成しているので、文字を綺麗に出したいなら
CSS 側（`docs/brand/ogp.html`, `hero.html`）の修正が最短。画像生成AIで背景素材だけ作って差し替える場合:

```
1200×630 の横長。深い紺から黒へのグラデーション。下辺の中央から金色の光が
扇状に立ち上がる。左右に抽象化された睡蓮の葉の輪郭がごく淡く沈んでいる。
中央は完全に空白（テキストを載せるため）。文字は一切入れない。
＋共通スタイル指定
```

## 3. デモ動画で使う生成カット

構成・ナレーション・収録手順は `docs/demo-script.md` にまとめてある。生成動画を使うのは
前後の「引き」と「締め」だけで、実機デモの部分は必ず画面収録にする。

### カット1（0:00–0:08）オープニング

```
日本語:
暗い美術館の展示室。カメラは床すれすれからゆっくり上へパンし、床置きの照明から
立ち上がる金色の光が一枚の額縁を照らしていく。額の中は抽象化された青と金の水面。
人物は登場しない。空気中に細かな塵が金色に舞う。カメラの動きは非常にゆっくり、
手ブレなし。8秒。
＋共通スタイル指定
```

```
English:
slow tilt up from the gallery floor, a floor uplight sending a shaft of warm gold
across a single ornate frame holding an abstract blue-and-gold water surface,
fine dust motes glowing in the beam, no people, extremely slow and steady camera,
8 seconds, cinematic, shallow depth of field
+ common style suffix
```

### カット4（1:05–1:20）スケール感

```
日本語:
暗い空間に、金色の細い光の線が無数に走り、格子状のネットワークを描いていく。
線が交わる点が淡く光る。文字や図形は入れない。カメラはゆっくり後退し、
全体が一つの大きな構造に見えてくる。手ブレなし。6秒。
＋共通スタイル指定
```

### カット5（1:20–1:30）クロージング

```
日本語:
暗い展示室の出口の扉が開き、向こうから金色の光が床に長く伸びる。
カメラはその光へゆっくり近づく。人物は写さない。最後は光で画面が満たされる。
6秒。
＋共通スタイル指定
```
