# デモ動画 台本（90秒）

構成は「① 引き（世界観）→ ② 実機デモ（主役）→ ③ 学習ループ（差別化）→ ④ 締め」。
**実機デモは必ず画面収録**する。生成動画で代替すると審査員の信頼を失う。生成動画は前後の「引き」と「締め」に使う。
カット別の生成プロンプトは `docs/slide-prompts.md` の「3. デモ動画で使う生成カット」にある。

## 0. 尺の割り当て

| カット | 時間 | 素材 | 内容 |
| --- | --- | --- | --- |
| 1 | 0:00–0:08 | 生成動画 or `01-title.png` にゆるいズーム | オープニング（暗い展示室、床からの光） |
| 2 | 0:08–0:35 | 画面収録 | 解説生成 → 読み上げ → 見どころ → 多言語 |
| 3 | 0:35–1:05 | 画面収録 ＋ `04-loop.png` を重ねる | 学習ループ（質問・指摘・アーカイブ更新） |
| 4 | 1:05–1:20 | 生成動画 ＋ `07-numbers.png` の数字 | スケール感 |
| 5 | 1:20–1:30 | 生成動画 or `08-closing.png` | クロージングと URL |

カット2（実機）に最も長く時間を割く。削るならカット4から削る。

## 1. カット1（0:00–0:08）オープニング

映像: 床すれすれから上へのゆっくりしたパン。床置き照明から立ち上がる金色の光が一枚の額縁を照らす。人物なし。

ナレーション / 字幕:

> 美術館で、いちばん知りたいのは「この絵は、何なのか」。

## 2. カット2（0:08–0:35）実機デモ — 画面収録

収録手順（この順番だと迷わない）:

1. トップページを開く（金色のワードマークに床からの光が入る瞬間を見せる）
2. 「睡蓮」と入力 → 解説が出るまで（**事前にキャッシュを温めておく**。初回生成は1〜3分かかる）
3. 読み上げを再生し、文が進むごとにハイライトされるのを見せる
4. 「見どころ」をタップして拡大表示
5. 言語を **EN** に切り替えて英語で読み上がるところ（**英語版も事前に温めておく**。言語別キャッシュのため未生成だと約60秒待つ）
6. 「裏話・エピソード」をタップ（金色のリングが弾ける演出）
7. 「次におすすめ」に別の作品が並ぶところ、♡を連打してハートが舞うところ

ナレーション / 字幕:

> 作品名を入れるか、写真を撮る。それだけで、AIキュレーターが解説を書き、読み上げます。
> 見どころは絵の上に。言語は5つ。気になれば、その場で質問もできます。

## 3. カット3（0:35–1:05）学習ループ — 画面収録＋図

収録手順:

1. 質問を入力して回答が返るところ
2. 👎 を押し、「事実が違う」をタップ
3. **AIキュレーターが一文で「何をどう直したか」を返す**ところ（数秒で返る）

そのあと `docs/images/slides/04-loop.png` の円環図をアニメーションで重ねる。

ナレーション / 字幕:

> ここが、貸出式の音声ガイドと違うところです。
> あなたの質問への回答は解説に残り、あなたの指摘はAIが読んで修正案を作り、承認されればアーカイブそのものが書き換わります。
> 聴いた履歴は好みのベクトルになって、次の一枚を選びます。
> つまりこのガイドは、聴かれるほど賢くなります。

## 4. カット4（1:05–1:20）スケール感

映像: 金色の細い光の線が格子状のネットワークを描き、カメラがゆっくり後退。文字は後乗せ。

重ねる数字（`07-numbers.png` と同じ値を使う。値は撮影前に実測し直す）:

- 解説アーカイブ **436件**
- 対応言語 **5言語**
- テーマ別ツアー **8本**
- sitemap 登録 **235 URL**（Google Search Console 登録済み）

ナレーション / 字幕:

> 解説はすでに400件を超え、5言語ぶんが積み上がっています。

## 5. カット5（1:20–1:30）クロージング

映像: 出口の扉が開き、向こうから金色の光が床に長く伸びる。最後は光で画面が満たされる。

ナレーション / 字幕:

> ArtFreeGuide。聴くほど賢くなる、美術館のAI音声ガイド。

最後に URL を静止表示: `art-free-guide.taira-sakakibara.workers.dev`

## 6. 音・字幕・書き出しの実務メモ

- **BGM**: アプリ自身がプロシージャルBGM（Web Audio のドローン）を鳴らす。デモ音声にそれが入るなら別のBGMは重ねない。重ねるなら弦のロングトーンだけの静かなものを −20dB 程度で。
- **読み上げ音声**: Web Speech API はブラウザ側で鳴るため、**画面収録時にシステム音声も録る**設定を確認する（これが抜けると「読み上げが売り」なのに無音になる）。
- **字幕**: 音を切って見られることがあるので、ナレーションは必ず字幕に。
- **書き出し**: 1920×1080 / 30fps / H.264。SNS用に 1:1 と 9:16 も切り出す。
- **尺**: 90秒が上限の目安。

## 7. 撮影前チェックリスト

- [ ] デモに使う作品の **日本語** 解説がキャッシュ済み（`node scripts/warm_cache.mjs --guides-only --locales=ja --limit=20 --concurrency=1`）
- [ ] デモに使う作品の **英語** 解説がキャッシュ済み（`--locales=en`。言語別キャッシュのため未生成だと初回に約60秒かかる）
- [ ] 「裏話・エピソード」を一度押して温めておく
- [ ] 画像が出ない作品（ピカソ・ダリ・マグリット等の著作権保護作品）はデモに使わない
- [ ] ♡ が 0 のままだと演出が地味なので、事前に何回か押しておく
- [ ] ブラウザをスーパーリロードして、古いキャッシュのバナーが出ないことを確認
- [ ] カット4で出す数字を実測し直す（アーカイブ件数・sitemap の URL 数）
