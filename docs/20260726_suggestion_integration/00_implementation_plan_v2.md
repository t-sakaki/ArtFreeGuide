## 改訂のポイント

### 1. mode toggle を **概要 / 詳細** の2つに簡素化

**旧:** 概要 / 標準 / 詳細
**新:** **概要 / 詳細**

「標準」の用語が曖昧（具体的には何？とのご指摘）。
「標準」は役割不明だった。**概要 + 詳細** の2段階で必要十分。

- **概要**: 100〜150文字の簡潔な基本解説（作品名、作者、制作年、技法など）
- **詳細**: 長文・深掘りの解説（時代背景、技法詳細、関連作品比較）

### 2. chat 入力欄を **解説文の後ろ** に移動

**旧配置:**
```
[mode toggle]
[chat 入力欄 + サジェスト]       ← 上に置いていた
[解説 (Highlights)]
```

**新配置:**
```
[mode toggle]
[解説 (Highlights)]
[chat 入力欄 + サジェスト]       ← 解説の後に移動
[最下部固定バー]
```

理由: 「質問する前にまず解説を読む」のが自然な順序。

### 3. 「さらに詳しく」機能を **AIサジェスト** で代替

**旧:** 固定「さらに詳しく」ボタン → 標準解説を追記
**新:** AI生成の動的サジェスト💡📜❓が同じ役割を提供
- 「時代背景をもっと教えて」「技法の具体例は?」等
- 選択するとchat欄に言葉がセット → AIが返す → 解説エリアに追記

→ 2026-07-26前半で実装した AI サジェストはそのまま活かす。

### 4. 旧フィードバックUI **完全削除**

`★★★★★`, 「解説の評価」, 「フィードバック・ご意見」テキストボックス
は AntGravity によって既に削除済みのはずだが、表示されたという
ユーザー報告より、**まだ残骸が残っている**。

→ Task 1 で確実に消す。
